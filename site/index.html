Тема на входе. Готовый ролик на выходе.

Пишешь одну строку — получаешь короткое видео для Reels, Shorts и TikTok: ИИ-сценарий, живой голос, ИИ-визуал или бесплатные стоки, музыка под настроение и караоке-субтитры по словам. За три минуты и ≈ 50 кредитов.

MoneyPrinterTurbo был принтером. Это — пушка.

Конвейер

Семь стадий — одна команда

Каждая стадия сохраняет результат. Упало на рендере — продолжишь с рендера, за голос и картинки второй раз не платишь.

01 · СЦЕНАРИЙ

Хук в первые три секунды

LLM пишет сценарий по сценам: у каждой — свой текст, свой визуальный промпт и поисковые слова для стоков. Длина откалибрована по реальной скорости голоса.

02 · ГОЛОС

30 голосов, стиль и темп

Gemini TTS: Promo/Hype, Newscaster, Whisper… Один запрос на сцену — границы сцен точные и бесплатные.

03 · ТАЙМИНГ

Whisper по словам

Пословные таймкоды, выровненные на текст сценария. Субтитры не «плывут».

04 · ВИЗУАЛ

На каждую сцену

ИИ-картинки с эффектом Кена Бёрнса, ИИ-видео (Seedance, Veo, Kling, Grok) или бесплатные стоки Pexels/Pixabay с автофолбэком.

05 · МУЗЫКА

Трек под настроение

Suno генерирует инструментал под сценарий; под голосом музыка приглушается сайдчейном.

06 · РЕНДЕР

Remotion в один проход

Караоке-субтитры (4 пресета), переходы, титул, финальная плашка, прогресс-бар. Громкость −14 LUFS.

07 · ПУБЛИКАЦИЯ

YouTube · TikTok · Instagram · LinkedIn

Бесплатно через Composio: заголовок, описание и хэштеги уже готовы.

Возможности

Всё, что нужно фабрике роликов

🖥️

Веб-интерфейс

Форма, живая смета в кредитах, список задач, прогресс по стадиям, плеер, кнопки «скопировать» заголовок и хэштеги.

⌨️

CLI и батчи

cannon make "тема", cannon batch tasks.jsonl --parallel 2 — до 100 роликов за прогон, resume любой задачи.

🔌

REST API + Swagger

Дёргай из n8n, Make или своего бэкенда: POST /api/tasks → готовый MP4, обложка, тексты.

🤖

Скилл для ИИ-агентов

Claude Code или Cursor ставит и запускает всё сам по одной ссылке на SKILL.md и возвращает путь к файлу.

🐳

Docker

Один docker compose up — Python, Node, ffmpeg и Chromium для Remotion уже внутри.

🎬

Три формата

9:16 для Reels/Shorts, 16:9 для YouTube, 1:1 для ленты — из одного сценария, с теми же субтитрами.

Запуск

Пять команд до первого ролика

# Python ≥ 3.11, Node ≥ 20, ffmpeg
git clone https://github.com/upsalesvideo/MoneyPrinterCannon
cd MoneyPrinterCannon
uv venv && uv pip install -e ".[mlx,publish]"
(cd remotion && npm install)
cp .env.example .env            # GENOSAI_API_KEY=...

cannon doctor                  # ключ, ffmpeg, node, whisper
cannon make "Почему коты спят шестнадцать часов" --aspect 9:16
cannon serve                   # веб-интерфейс + API
  1. Ключ Genosai — на genosai.io в разделе API. Без VPN и зарубежных карт.
  2. Смета до траты. cannon estimate "тема" покажет кредиты по стадиям; make спросит подтверждение.
  3. Ролик 45 секунд на ИИ-картинках стоит ≈ 40–60 кредитов, на ИИ-видео ≈ 200–300.
  4. Стоки бесплатно — добавь ключи Pexels/Pixabay и включи --visuals stock или mixed.
  5. Свой сценарий? --script-file text.txt — слова не тронем, только разложим по сценам и подберём визуал.

Публикация

Выложить — бесплатно

MoneyPrinterTurbo постит через платный upload-post.com. Здесь — Composio: управляемый OAuth для YouTube, Instagram, TikTok и LinkedIn, 100 000 вызовов в месяц бесплатно, свои OAuth-приложения регистрировать не нужно.

COMPOSIO_API_KEY=ak_...            # бесплатный ключ platform.composio.dev
cannon connect youtube            # одна ссылка, один раз
cannon publish <task_id> --to youtube,tiktok --privacy public
cannon make "Тема" --publish youtube --privacy unlisted   # сгенерил и выложил
